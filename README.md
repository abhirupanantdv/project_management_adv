# project_management_adv

Enterprise Project Management & Tracking Cockpit with ERPNext integration.

## Features
- **Interactive Project Cockpit**: KPI summaries, progress tracking, budget and cost monitoring.
- **Kanban Board**: Drag-and-drop task workflow management.
- **Project Table View**: Filterable, searchable table with inline status indicators.
- **ERPNext Integration**: REST API connectors for live project and task synchronization.
- **Modern React & Tailwind UI**: Responsive glassmorphic dark theme and interactive analytics.

## Getting Started

### Prerequisites
- Node.js (v18+)
- Python (v3.9+)

### Installation & Running

#### React Project Cockpit
```bash
cd react_project_cockpit
npm install
npm run dev
```

The application will be accessible at `http://localhost:3000/`.
